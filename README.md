# MonoCart | مونو كارت 🛒✨
### منصة المقاضي وسلة المنزل الذكية المتزامنة في الوقت الفعلي

منصة تفاعلية حديثة لإدارة مقاضي المنزل ومشتريات السوبرماركت في الوقت الفعلي مع مزامنة سحابية فائقة السرعة، دعم اللغتين (العربية والإنجليزية)، فحص النواقص والبدائل، تصدير التقارير (PDF & Collage)، ودعم الوضع الداكن الفخم.

---

## 🌟 المميزات الرئيسية
- 🛒 **وضعان مخصصان**:
  - **وضع المتسوق (Shopper Mode)**: مخصص للشخص المتواجد بالسوبرماركت للتحقق السريع، رصد البدائل، وإتمام التسوق وحفظ السجل.
  - **وضع مراجع ومحضر المقاضي (Preparer/Reviewer Mode)**: مخصص لإضافة الأغراض، كتابة الملاحظات، وجدولة المشتريات.
- 📸 **التعامل مع الصور وتكبيرها (Lightbox Zoom)**:
  - إرفاق صور للمنتجات والبدائل مباشرة عبر الكاميرا أو المعرض.
  - إمكانية تكبير وتصغير وتحريك أي صورة بملء الشاشة مع التكبير الدقيق.
- ☁️ **مزامنة سحابية فورية (Supabase Live Sync)**:
  - دعم متعدد للمنازل (Home ID).
  - التحقق الفوري من عدم تكرار أرقام المنازل عند التسجيل.
  - حفظ السجلات السابقة مع إمكانية استرجاعها أو استيراد النواقص فقط.
- 📦 **تصدير كولاج وطباعة PDF**:
  - تصدير شبكي 5 أصناف بالصف لتوفير الورق وسهولة القراءة.
- 🌙 **وضع داكن عصري**: أزرق كحلي عميق مع بطاقات بيضاء واضحة ولمسات برتقالية أنيقة.
- 💬 **دعم فني عبر واتساب**: زر مدمج للتواصل مع الدعم الفني مباشرة.

## 🚀 تشغيل المشروع محلياً (Local Development)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

## 📂 بنية المجلدات المرفوعة على GitHub
- `index.html` : الصفحة الرئيسية وعناصر الواجهة التفاعلية.
- `src/main.js` : كود المنطق، معالجة السجلات، الربط مع Supabase والمزامنة.
- `src/style.css` : نظام التصميم الكامل، الوضع الداكن، والرسوم المتحركة.
- `public/` : الشعار وملفات الوسائط العامة.
- `package.json` : حزم المشروع وإعدادات البناء.
- `.gitignore` : استبعاد ملفات الكاش و node_modules.
